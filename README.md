# Практика — дневник медитации

Веб-приложение для ежедневной практики, которое ставится на экран «Домой» айфона и работает без интернета. Сделано под конкретную программу: базовая практика (ходьба → сидячая → благодарность), пу-то, дыхание 50/50 и отказ от вредных привычек.

Живой пример: https://nhc.formachines.ai (данные остаются только в вашем браузере).

## Что умеет

- **Базовая практика.** Ходьба N минут → сидячая N минут → экран благодарности. Колокол: один удар на старте, два при переходе, три в конце. N по умолчанию следует программе: 5 минут на часть, +1 каждый понедельник до 15 (цель дня 10 → 30 минут); ползунком можно поставить любое.
- **Пу-то.** Секундомер «старт — финиш» для ходьбы с «пу» на правый шаг и «то» на левый.
- **Утро.** Настроение и энергия 1–5, три важных дела.
- **Итог дня.** Проверка утренних дел, настроение и энергия, практики задним числом (если телефона не было под рукой), дыхание 50/50 — какую часть дня удавалось держать половину внимания на дыхании, привычки: алкоголь, никотин, марихуана.
- **Два стрика:** практика (была базовая практика) и трезвость (все три привычки «не было»), плюс «дней без …» по каждой привычке.
- **Календарь.** Заливка — доля цели дня, точка — пу-то, буквы А Н М — привычки, зелёная точка — чистый день. Тап по дню — карточка с правкой.
- **Вибро.** Пуш-уведомления в конце ходьбы и в конце практики вибрируют даже на заблокированном экране (нужен свой сервер, см. ниже).
- Экспорт JSON / CSV, импорт, светлая и тёмная темы, журнал отладки в настройках.

## Как это устроено

- Чистый HTML + CSS + JavaScript, без сборки и зависимостей: `index.html`, `app.js`, `style.css`, `sw.js` (офлайн-кэш и пуши), `manifest.webmanifest`.
- **Данные — только в `localStorage` телефона.** На сервер ничего из записей не уходит. Удаление иконки с экрана «Домой» стирает данные, поэтому делайте экспорт.
- **Колокол при заблокированном экране.** iOS усыпляет JavaScript, но не прерывает начатое аудио. Поэтому вся оставшаяся часть сессии собирается в один WAV-файл (тишина + удары) и запускается нажатием «Начать».
- **Идущая сессия переживает перезапуск**: время считается по меткам, чекпоинт лежит в `localStorage`.
- **Вибро.** Safari на iOS не умеет `navigator.vibrate`, но Web Push в приложении с экрана «Домой» (iOS 16.4+) вибрирует. При старте практики приложение сообщает серверу время двух сигналов. Сервер `server/push.py` в нужную секунду шлёт пустой пуш, а сервис-воркер спрашивает у сервера тег и показывает уведомление. На сервер уходит только адрес подписки браузера и время.

## Запустить у себя

Локально, без пушей:

```bash
python3 -m http.server 8767
```

и открыть http://localhost:8767.

На своём сервере (Ubuntu с nginx, certbot и `python3-cryptography`):

1. A-запись домена → IP сервера.
2. `cp deploy.env.example deploy.env` и заполнить.
3. `./deploy.sh` — заливает файлы в `/var/www/<slug>`, ставит пуш-сервис (`/opt/nhc-push`, systemd `nhc-push`, порт 8790 на localhost), вхост nginx с `/api/push/` и выпускает сертификат. Скрипт можно запускать повторно — он обновит только изменившееся.
4. На айфоне открыть сайт в Safari → «Поделиться» → «На экран „Домой“». В настройках приложения включить «Вибро-уведомления».

После правок в `app.js`, `style.css` или `index.html` поднимайте `CACHE` в `sw.js`, иначе телефон покажет старую версию из кэша.

## Пуш-сервис

`server/push.py` — стандартная библиотека Python и `cryptography`. VAPID-ключ генерируется при первом запуске и лежит в `/var/lib/nhc-push/`, там же состояние (переживает рестарт).

API:
- `GET /api/push/key` — публичный ключ;
- `POST /api/push/schedule {endpoint, jobs}` — заменить ожидающие сигналы устройства;
- `POST /api/push/last {endpoint}` — последний отправленный тег.

Ограничения от злоупотреблений:
- принимаются только адреса push-сервисов Apple, Google, Mozilla и Microsoft;
- не больше 4 сигналов на устройство;
- не дальше 4 часов вперёд;
- не больше 60 запросов в минуту с одного IP.
